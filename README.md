# EDEN OS

**Sovereign AI Refinement, Measurement, Provenance and Efficiency Infrastructure**

EDEN OS is an experimental framework for measuring, verifying and recording AI production, refinement, resource use, provenance and quality-preserving efficiency.

This public repository is the canonical public source tree for EDEN OS development artifacts released by the project.

## Core concepts

- Chronometric Geometry / Chrononav
- Semantic Mass and Compression Telemetry
- EDEN Observation Pipeline
- Marbles: content-addressed production/provenance objects
- HyperMarble and Hive research
- CRV / RSU experimental measures
- EEA evidence/accreditation levels
- Infrastructure accountancy
- Reproducibility and fail-closed verification

## Evidence discipline

EDEN OS distinguishes experimental/protocol constructs from externally demonstrated facts. Simulations, logical namespace capacity, candidate efficiency and protocol deployment records do not by themselves establish real-world infrastructure deployment, financial value, recognized accreditation, or independently verified savings.

## Security

Private signing keys, credentials, access tokens and other secrets are intentionally excluded from the public repository.

## Status

Experimental / research software. See individual specifications, tests and evidence records for the status and scope of each component.
